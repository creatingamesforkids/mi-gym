# MI-Gym

Oefenspel motiverende gespreksvoering voor MBO Sociaal Werk niveau 4.

Vier stappen per casus: engageren, focussen, ontlokken, plannen.
Casussen: Amir (school), Dennis (drinken), Karim (gezin).

## Speel het

Open `index.html` in de browser, of na het aanzetten van GitHub Pages:

https://creatingamesforkids.github.io/mi-gym/

## GitHub Pages aanzetten (eenmalig)

1. Ga naar https://github.com/creatingamesforkids/mi-gym/settings/pages
2. Onder **Build and deployment** kies **Source**: Deploy from a branch
3. Branch: `main`, folder: `/ (root)`
4. Save. Na ongeveer een minuut werkt de link hierboven.
